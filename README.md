# Clínica Ubertriz de Usabilidade

Ferramenta de ensino de Interação Humano-Computador com **500 problemas de usabilidade**, 50 por heurística de Nielsen, cada um resolvido segundo a UBERTRIZ:

heurística violada → tensão → contradição (C01–C36) → metaoperador (U01–U36) → escala (micro/meso/macro) → verificação pela idealidade (I01–I12) e métrica.

## Como usar

Acesse pelo GitHub Pages: https://gersonklein.github.io/clinica-ubertriz/ — ou abra `index.html` em qualquer navegador; não há instalação nem servidor.

- **Problemas** — catálogo com busca e filtros por heurística, escala, família de metaoperador e gravidade. A solução aparece ao abrir o problema; o raciocínio UBERTRIZ fica oculto até ser pedido.
- **Heurísticas** — as 10 heurísticas com os metaoperadores mais usados em cada uma.
- **Método** — os 6 passos do raciocínio, com as tabelas completas recolhidas.
- **Treino** — exercício em duas etapas: identificar a heurística e escolher a família de metaoperadores.

O progresso de estudo fica salvo no navegador de cada pessoa.

## Arquivos

- `index.html` — a ferramenta (dados na lista `RAW`, um problema por linha).
- `conversa_TRIZ_SUPERTRIZ_UBERTRIZ_completa.md` — texto-base da TRIZ, SUPERTRIZ e UBERTRIZ.
